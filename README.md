# 🌬️ Wind Turbine Power Generation Project

## 📌 Project Overview
This project focuses on the design and implementation of a wind turbine system to generate renewable electrical energy from wind power. The goal is to demonstrate how wind energy can be converted into usable electricity using mechanical and electrical components.

It also includes a live interactive simulation to visualize the working of a wind turbine system.

## ⚙️ Working Principle
A wind turbine works on the principle of energy conversion:

1. Wind blows and rotates the turbine blades
2. The rotor spins the shaft
3. The shaft drives a generator/dynamo
4. The generator converts mechanical energy into electrical energy
5. The produced electricity can be stored or used to power loads

---

## 🧩 Main Components Used

| Component        | Purpose                         |
| ---------------- | -------------------------------- |
| Turbine Blades   | Capture wind energy             |
| Rotor            | Transfers blade motion to shaft |
| Shaft            | Connects rotor to generator     |
| Generator/Dynamo | Produces electricity            |
| Tower/Base       | Supports the turbine            |
| Wires            | Carry electrical output         |
| LED / Load       | Demonstrates power generation   |
